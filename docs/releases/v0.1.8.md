# v0.1.8: Internal Tooling Only

**Date:** 2026-06-28

Internal tooling and packaging hygiene only — **no runtime or public API changes**.
Binaries are functionally identical to v0.1.7; this release exercises the updated
release/signing path.

## Changes

- **Packaging**: the npm payload no longer bundles the standalone binaries
  (`files` excludes `dist/release`; tarball ~78 kB), and the template is marked
  `"private": true` with a `publish.yml` guard — it is a template to be CDRL'd,
  not a published package.
- **Release tooling**: canonical `TUVAN_RELEASE_TAG` (bare `TAG` kept as a
  deprecated alias); `release-sign` now runs the `release-guard-tag-version`
  check first; new `make release-verify-keys` and `make release-verify-signatures`
  targets.
- **Developer experience**: the pre-commit/pre-push hooks now mirror CI's
  `goneat format` gate (catching Markdown/YAML drift locally); `make fmt` formats
  Markdown/YAML in addition to source.

## Notes

- This is a template; CDRL it (Clone → Degit → Refit → Launch) rather than
  installing from a registry. See `docs/development/fulmen_cdrl_guide.md`.
